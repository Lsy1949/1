# 生涯心旅 · 核心技术与功能说明

> **文档用途**：面向功能评审，概述平台的核心技术能力与功能范围。
> **说明**：本文不含代码、工程结构与接口细节，只说明「用什么技术、提供什么功能、规则是什么」。

## 1. 产品定位

面向高校学生的心理健康与生涯发展服务平台。一套前端支撑多所学校独立站点：各站点拥有独立域名、独立品牌与独立模块清单，内容与数据由后端统一提供，平台不设管理后台。

- **用户**：学生（PC 与移动端自适应）、学校（租户）、内容与咨询团队。
- **本期已实现**：首页、心晴阅读、心事广场、心理测评、咨询中心、时光胶囊、AI 对话、个人中心与设置、登录与错误页。
- **不在本期**：管理后台、在线支付、真实音视频咨询、内容审核工作流。

## 2. 核心技术

### 2.1 技术选型

| 能力 | 技术 | 作用 |
|---|---|---|
| 界面框架 | React 18 + TypeScript | 组件化开发，类型约束降低联调偏差 |
| 构建与打包 | Vite 7 | 快速构建，页面按需拆分加载 |
| 组件库 | Ant Design 6 | 表单、弹层、提示等复杂控件体验统一 |
| 路由 | 前端路由 | 页面级懒加载，首屏更快 |
| 服务端数据 | React Query | 缓存、重试、失效与乐观更新 |
| 实时通道 | SignalR | 通知推送与强制下线 |
| 多语言 | 自建轻量方案 | 三套语言包，无额外依赖 |
| 演示数据 | Mock Service Worker | 后端未就绪时前端可独立演示 |

### 2.2 关键能力

| 能力 | 说明 |
|---|---|
| 多租户 | 按私有化参数、子域名、默认站点三级识别；品牌、主题与模块清单按学校下发；缓存优先并后台刷新，失败回退默认配置 |
| 访问控制 | 会话分校验中、已登录、未登录三态；模块开关与路径清单两级控制，同时作用于导航与访问；被关闭页面显示无权限而非页面不存在 |
| 品牌与主题 | 预置色板或自定义主色派生七档品牌色；明暗支持浅色、深色、跟随系统；用户偏好优先于学校默认；首帧预置避免闪色 |
| 数据与缓存 | 列表缓存 30 秒、菜单 10 分钟；写操作后按业务域刷新；点赞等乐观更新失败自动回滚；搜索防抖并保留上一页结果 |
| 接口与安全 | 服务端会话，前端不保存登录凭证；写操作校验跨站令牌；请求携带租户标识；错误统一为可读中文提示 |
| 实时消息 | 通知推送与未读计数、强制下线、自动重连并重新订阅本校消息、心跳保活 |
| 多语言 | 简体中文、繁体中文、英文；缺词条回退中文；切换即时生效并记忆选择 |
| 无障碍 | 点击热区不小于 44 像素、键盘可达、焦点可见、状态播报、动效按系统偏好降级 |

## 3. 功能模块

### 3.1 模块总览

| 模块 | 核心功能 | 需登录 |
|---|---|---|
| 首页 | 品牌横幅、轮播、新闻公告、数据展示、关于与联系方式 | 否 |
| 心晴阅读 | 文章中心、分类与合集、列表搜索、文章详情、相关推荐 | 否 |
| 心事广场 | 动态列表与筛选、发布动态、详情与评论、点赞 | 否 |
| 心理测评 | 量表中心、在线作答、结果解读、历史记录、成长面板 | 否 |
| 咨询中心 | 咨询师列表与详情、预约与取消、我的预约、常见问题 | 否 |
| 时光胶囊 | 胶囊列表与筛选、新建与编辑、详情、删除、到期倒计时 | 否 |
| AI 对话 | AI 咨询、AI 陪伴、流式对话（悬浮入口与咨询中心内均可进入） | 否 |
| 个人中心 | 资料展示、成长统计、偏好设置、联系方式换绑 | 是 |
| 设置 | 主题与语言偏好、隐私与通知开关、账号退出 | 是 |
| 登录与错误页 | 账号登录、学校选择、记住我、无权限与页面不存在引导 | 否 |

### 3.2 关键业务规则

| 模块 | 规则 | 边界 |
|---|---|---|
| 首页 | 轮播 5 秒自动切换，支持拖拽、键盘与手动切换；数字滚动在进入视口时触发一次 | 联系表单仅前端提示，不落库 |
| 心晴阅读 | 关键词 300 毫秒防抖；中心页首屏 6 条可展开全部；相关推荐最多 4 条；详情显示阅读进度 | 评论为演示数据；点赞与收藏为本地状态 |
| 心事广场 | 正文不超过 500 字、图片不超过 6 张、话题不超过 3 个，正文与图片至少一项；点赞即时反馈，失败回滚 | 分享与话题操作仅提示；每日一问与社区公约为静态内容 |
| 心理测评 | 全部题目作答后方可提交；选择后 300 毫秒自动进入下一题；记录作答时长；中途退出需二次确认；计分在服务端完成；积分按历史条数累计 | 报告下载与分享为提示；雷达组均值与 AI 洞察为静态内容 |
| 咨询中心 | 预约分四步并可回看摘要；可选日期为次日起 7 天；支持取消预约；咨询师卡片可一键带入预约表单 | 时段表为预置；公告、常见问题与流程为静态内容 |
| 时光胶囊 | 草稿自动保存并在下次进入时恢复；未到期显示倒计时；支持滑动删除与键盘操作；正文支持富文本与图片 | 草稿不含图片；状态与开启方式文案由前端映射 |
| AI 对话 | 流式逐字输出；发送期间禁止并发；中断保留已生成内容 | 会话不持久化，刷新即清空；未接入真实服务时使用本地预设话术 |
| 个人中心 | 主题与语言偏好即时生效并播报；联系方式换绑为三步流程，含 60 秒重发倒计时 | 保存、统计、设备列表与隐私开关为界面占位 |
| 登录 | 学校选择仅在主域出现；跨校登录跳转对应站点；登录后回到来源页并校验可达性；已登录访问直接跳转 | 暂无图形验证码；第三方登录为占位 |
| 错误页 | 无权限页说明原因；页面不存在页提供四屏引导与小游戏，支持滚轮、触摸与键盘翻页 | 幻灯片图片为外链；游戏文案为中文 |
