# 生涯心旅 · 功能与技术说明（评审版）

> **文档用途**：面向功能评审，说明平台的核心技术能力、功能范围、业务规则与已知边界。
> **阅读对象**：产品、设计、测试、业务方与验收人员。
> **说明**：本文只描述「做什么、怎么做、边界在哪」，不涉及代码、工程结构与接口字段；实现级细节另见技术文档。

## 1. 产品定位与范围

### 1.1 定位

面向高校学生的心理健康与生涯发展服务平台。一套前端支撑多所学校独立站点：每所学校拥有独立域名、独立品牌与独立模块清单，数据与内容由后端统一提供。平台无管理后台，站点配置由后端下发。

### 1.2 角色与场景

| 角色 | 使用方式 | 主要诉求 |
|---|---|---|
| 学生 | 浏览器访问，PC 与移动端自适应 | 测评、阅读、倾诉、预约咨询、记录心情 |
| 学校（租户） | 独立域名或子域名站点 | 品牌自主、模块按需开通 |
| 内容与咨询团队 | 通过后端维护内容、量表与排班 | 内容及时更新、预约可管理 |
| 评审与验收方 | 演示环境 | 功能完整可走通、边界清晰 |

### 1.3 本期范围

| 已实现 | 不在本期 |
|---|---|
| 首页、时光胶囊、心事广场、心理测评、心晴阅读、咨询中心（含 AI 对话与陪伴）、个人中心与设置、登录与错误页 | 管理后台、在线支付、真实音视频咨询、内容审核工作流 |
| 三语切换、明暗主题、多租户品牌与模块裁剪、实时通知、演示数据 | 消息中心独立页面、账号自助注册与找回密码 |

## 2. 核心技术

### 2.1 技术选型

| 能力 | 技术 | 作用 |
|---|---|---|
| 界面框架 | React 18 + TypeScript | 组件化开发，类型约束降低联调偏差 |
| 构建与打包 | Vite 7 | 快速构建，页面按需拆分加载 |
| 组件库 | Ant Design 6 | 表单、弹层、提示等复杂控件的统一体验 |
| 路由 | 前端路由 | 页面级懒加载，首屏更快 |
| 服务端数据 | React Query | 缓存、重试、失效与乐观更新 |
| 实时通道 | SignalR | 通知推送、强制下线 |
| 多语言 | 自建轻量方案 | 三套语言包，无额外依赖 |
| 演示数据 | Mock Service Worker | 后端未就绪时前端可独立演示 |

### 2.2 分层结构

| 层 | 职责 |
|---|---|
| 页面层 | 每个页面独立加载，持有自身的数据请求 |
| 业务组件层 | 模块内组件，只消费数据，不直接访问接口 |
| 数据访问层 | 统一请求出口、租户标识注入、错误归一化 |
| 状态层 | 会话、租户、主题、实时四类全局状态 |
| 壳层 | 布局、导航、访问守卫、主题注入 |
| 配置层 | 页面注册、租户配置解析与合并 |

### 2.3 启动与恢复

| 步骤 | 行为 | 对用户的影响 |
|---|---|---|
| 1 | 首帧预置明暗主题与品牌色 | 无闪白、无闪色 |
| 2 | 演示数据就绪（仅开发环境） | 无后端也能完整浏览 |
| 3 | 渲染界面，先使用默认租户配置 | 首屏不等待接口 |
| 4 | 读取租户缓存并后台刷新 | 品牌与模块清单即时生效 |
| 5 | 校验会话 | 已登录直接进入，未登录按需引导 |

### 2.4 数据与状态策略

- 会话以服务端为准，本地只保留「记住我」偏好，避免出现陈旧的已登录状态。
- 列表数据缓存 30 秒；菜单等低频数据缓存 10 分钟；窗口重新聚焦不强制刷新。
- 写操作成功后按业务域批量刷新，保证列表与详情一致。
- 点赞、评论点赞采用乐观更新：先给出反馈，失败自动回滚并提示。
- 关键词搜索 300 毫秒防抖，翻页保留上一页结果，避免闪烁。

## 3. 访问与权限

### 3.1 会话三态

| 状态 | 含义 | 界面表现 |
|---|---|---|
| 校验中 | 正在向服务端确认身份 | 显示加载，不闪现登录表单 |
| 已登录 | 服务端确认会话有效 | 展示用户信息，可进入受限页面 |
| 未登录 | 无有效会话 | 可浏览公开页面，受限页面引导登录 |

### 3.2 访问规则

| 是否登录 | 页面是否需登录 | 模块与路径是否开通 | 结果 |
|---|---|---|---|
| 未登录 | 否 | 是 | 正常访问 |
| 未登录 | 否 | 否 | 无权限页 |
| 未登录 | 是 | 任意 | 跳转登录，登录后回到原页面 |
| 已登录 | 任意 | 是 | 正常访问 |
| 已登录 | 任意 | 否 | 无权限页 |

被关闭的页面显示「无权限」而非「页面不存在」，用户直接输入地址也有可理解反馈。

### 3.3 两级开关

- **模块开关**（粗粒度）：控制整个模块的入口与页面，同时作用于导航与访问。
- **路径清单**（细粒度）：控制具体页面是否可达，未在清单内的页面一律不可达。
- 两者正交并存，同时生效；未下发路径清单时默认全量开放，一旦下发即严格按清单开放。
- 开关变更后无需刷新页面，导航与访问控制立即生效。

### 3.4 菜单生成

服务端下发菜单结构与模块标识，前端完成三道过滤：路径合法性校验、模块开关过滤、租户路径清单裁剪。菜单文案与图标由前端按当前语言解析，点击后带上筛选参数跳转。

## 4. 多租户与品牌

### 4.1 租户识别

按以下顺序判定，命中即停止：

| 顺序 | 来源 | 说明 |
|---|---|---|
| 1 | 私有化构建参数 | 专属部署时锁定单一学校 |
| 2 | 子域名 | 学校子域名站点；主域、通用前缀、多级前缀与 IP 不参与判定 |
| 3 | 默认站点 | 主站兜底 |

### 4.2 租户配置内容

| 配置项 | 内容 | 缺省行为 |
|---|---|---|
| 品牌 | 名称、Logo、站点图标、版权信息 | 使用内置默认品牌 |
| 主题 | 品牌主色、派生色阶、圆角、字体、语义色覆写 | 使用默认蓝色板 |
| 路径清单 | 本校开放的页面集合 | 未下发即全量开放 |
| 模块开关 | 五个业务模块的开关 | 按默认值 |
| 素材 | 登录背景、首页横幅 | 使用内置默认图 |

租户标识始终以前端解析结果为准，不采信服务端回显，避免跨站点串号。

### 4.3 主题与明暗

- 主题分三层：预置色板或自定义主色派生七档品牌色；语义色覆写仅作用于浅色模式；组件内部局部变量兜底。
- 明暗模式支持浅色、深色、跟随系统；用户选择优先于租户默认，选择结果按学校分别记忆。
- 品牌色、站点标题、站点图标随租户配置热更新，无需刷新页面。
- 首帧由预置脚本先行着色，避免加载过程中出现默认品牌闪现。

### 4.4 加载与降级

优先使用本地缓存的租户配置并立即生效，同时在后台刷新；无缓存时最多等待 1.5 秒，超时或失败回退默认配置，不阻塞页面。

## 5. 接口与实时能力

### 5.1 身份与安全

- 采用服务端会话，登录凭证不出现在前端存储中。
- 写操作需携带跨站请求令牌，由浏览器与服务端配合校验。
- 每次请求携带当前租户标识，后端据此隔离数据。

### 5.2 错误提示

| 场景 | 用户看到 |
|---|---|
| 登录凭证错误 | 账号或密码错误 |
| 会话过期 | 登录已过期，请重新登录，并回到登录页 |
| 服务端异常 | 服务器暂时不可用，请稍后再试 |
| 其他请求失败 | 优先展示服务端提示，否则提示请求失败 |
| 超时或断网 | 请求超时或网络错误 |

### 5.3 实时能力

| 能力 | 说明 |
|---|---|
| 通知推送 | 收到通知后未读计数加一，并全局提示 |
| 强制下线 | 服务端踢出后清理会话并回到登录页 |
| 自动重连 | 按 0、2、5、10 秒退避重连，成功后自动重新订阅本校消息 |
| 心跳 | 服务端 30 秒超时、15 秒保活，保证连接可用性 |

## 6. 多语言与无障碍

### 6.1 多语言

提供简体中文（默认）、繁体中文、英文三套语言包。缺词条时先回退简体中文，再回退词条名；切换语言即时生效并记住选择，同时同步页面标题与页面语言标记。

### 6.2 无障碍基线

- 可点击区域不小于 44×44 像素，视觉尺寸可更小，用透明区域扩展。
- 所有交互支持键盘操作与焦点可见，危险操作不只靠悬停呈现。
- 主题、语言等无焦点变化的状态切换提供读屏播报。
- 尊重系统「减少动态效果」偏好，自动降级动画与平滑滚动。

### 7.2 关键业务规则

| 模块 | 规则 | 边界 |
|---|---|---|
| 首页 | 轮播 5 秒自动切换，支持拖拽、键盘与手动切换；数字滚动在进入视口时触发一次 | 联系表单仅前端提示，不落库 |
| 心晴阅读 | 关键词 300 毫秒防抖；中心页首屏 6 条可展开全部；相关推荐最多 4 条；详情显示阅读进度 | 评论为演示数据；点赞与收藏为本地状态 |
| 心事广场 | 正文不超过 500 字、图片不超过 6 张、话题不超过 3 个，正文与图片至少一项；点赞即时反馈，失败回滚 | 分享与话题操作仅提示；每日一问与社区公约为静态内容 |
| 心理测评 | 全部题目作答后方可提交；选择后 300 毫秒自动进入下一题；记录作答时长；中途退出需二次确认；计分在服务端完成；积分按历史条数累计 | 报告下载与分享为提示；雷达组均值与 AI 洞察为静态内容 |
| 咨询中心 | 预约分四步并可回看摘要；可选日期为次日起 7 天；支持取消预约；咨询师卡片可一键带入预约表单 | 时段表为预置；公告、常见问题与流程为静态内容 |
| 时光胶囊 | 草稿自动保存并在下次进入时恢复；未到期显示倒计时；支持滑动删除与键盘操作；富文本编辑正文与图片 | 草稿不含图片；状态与开启方式文案由前端映射 |
| AI 对话 | 流式逐字输出；发送期间禁止并发；中断保留已生成内容 | 会话不持久化，刷新即清空；未接入真实服务时使用本地预设话术 |
| 个人中心 | 主题与语言偏好即时生效并播报；联系方式换绑为三步流程，含 60 秒重发倒计时 | 保存、统计、设备列表与隐私开关为界面占位 |
| 登录 | 学校选择仅在主域出现；跨校登录跳转对应站点；登录后回到来源页并校验可达性；已登录访问直接跳转 | 暂无图形验证码；第三方登录为占位 |
| 错误页 | 无权限页说明原因；页面不存在页提供四屏引导与小游戏，支持滚轮、触摸与键盘翻页 | 幻灯片图片为外链；游戏文案为中文 |

## 8. 演示与联调

- **演示模式**：开发环境默认开启，生产环境默认关闭；开启后可脱离后端完整演示全部流程。
- **演示账号**：任意账号名，密码统一为 111111。
- **租户差异**：默认站点与示例学校全量开放；另一所示例学校关闭心事广场，用于验证模块裁剪。
- **故障演练**：可模拟会话过期、跨站令牌缺失与接口异常，验证提示文案与降级行为。
- **数据重置**：演示数据保存在浏览器本地，清理浏览器数据即恢复初始状态。

## 9. 部署与环境

- **环境划分**：开发（本地代理后端）、预览（构建产物本地预览）、生产（静态托管加网关）。
- **网关要求**：业务接口与实时通道需转发，实时通道包含长连接升级；其余请求走静态资源与单页回退。
- **子路径部署**：站点基础路径、深链兜底页、路由基址三者必须一致，否则刷新深链会 404。
- **发布流程**：推送主分支后自动构建并发布到 GitHub Pages；生产未启用演示数据，后端未接入时出现接口错误提示属预期。
- **后端配合**：提供会话凭证、租户标识与跨站请求令牌响应头。

## 10. 功能边界与限制

| # | 现状 | 对评审的影响 |
|---|---|---|
| 1 | 实时连接仅在登录动作后建立，刷新页面不会自动恢复 | 刷新后需重新登录才能继续收到推送 |
| 2 | 个人中心与设置页的保存、导出、分享为界面占位 | 不作为本期验收项 |
| 3 | 页脚、错误页游戏、设置页部分文案为中文硬编码 | 多语言覆盖不完整 |
| 4 | 全局命令面板入口固定，不随租户裁剪 | 关闭模块的学校仍可见入口，点击进入无权限页 |
| 5 | 无权限页不展示导航与页脚 | 用户需借助浏览器返回 |
| 6 | 首页联系表单、文章评论、测评报告下载与分享为演示数据或提示 | 仅用于流程演示 |
| 7 | AI 对话未接入真实服务时使用本地预设话术 | 内容不构成咨询建议 |
| 8 | 登录暂无图形验证码，第三方登录为占位 | 安全性依赖服务端会话 |
| 9 | 测评计分在服务端完成，前端不做本地计算 | 后端未就绪时无法出结果 |
| 10 | 新增学校站点需预先配置品牌色 | 未配置时首帧短暂显示默认品牌色 |

## 11. 验收要点

- 未登录可浏览公开页面；进入受限页面跳转登录，登录后回到原页面。
- 关闭模块后导航入口消失，直接输入地址进入无权限页。
- 不同学校站点的品牌色、Logo、标题与模块清单互不影响。
- 明暗模式与三语切换即时生效，并在刷新后保持。
- 列表具备加载、空数据、错误三种状态，错误提示为可读中文。
- 点赞等即时操作先反馈，失败自动回滚。
- 测评需全部作答才能提交，结果与历史记录一致。
- 预约可提交、可取消，我的预约同步更新。
- 登录后未读通知计数随推送变化；被强制下线后回到登录页。
- PC 与移动端布局自适应，无横向滚动与内容截断。
